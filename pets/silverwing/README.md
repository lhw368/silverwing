# 银翼桌面小宠物

银白装甲、蓝色能量面板的 Q 版机甲娘。此目录提供用户现有银翼宠物的原始 v2 精灵图，无重绘或像素修改，采用仓库 MIT 许可。

## 直接使用

[打开公开领养链接](https://chatgpt.com/s/sharepet_6adb581ac1848191a06c39b0251bb72b)，在支持宠物功能的账号内领养。分享快照包含名称、描述和精灵图；不包含用户其他资料库内容。另一账号的实际领养安装尚未验证。

- `spritesheet.png`：1536×2288 RGBA，8 列 × 11 行，每格 192×208。
- `manifest.json`：供开发者读取的素材布局说明；不是 Codex 自动安装配置。
- `validation.json`：官方宠物校验工具对原始文件的结构验证结果。

前九行依次为 idle、running-right、running-left、waving、jumping、failed、waiting、running、review；第 9、10 行为顺时针 16 方向视线（0° 朝上，90° 朝右）。其中 `running` 表示处理工作时的动画，不是左右跑动。

在支持自定义宠物的 ChatGPT Work／Codex 界面中，可将精灵图交给宠物创建工作流，要求使用原始 v2 图片创建，无需重新生成。该流程需要当前账号支持自定义宠物。仓库本身不提供独立桌面运行程序，也不应将此 manifest 直接当作本机安装文件。
