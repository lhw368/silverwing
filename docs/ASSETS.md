# 素材与第三方许可

项目原创游戏源码和随附原创生成图像、音效按仓库 MIT 许可提供。AI 生成素材的可保护性可能因司法辖区而异；许可仅涵盖贡献者有权授予的权利。

- 银翼、绯刃、敌人、场景、机甲和技能图像：项目制作过程中使用图像生成工具生成；各素材目录内保留的 README、manifest 和生成提示记录说明其来源与动画限制。角色采用关键姿势动画。
- 音频：项目内合成音效／音乐。未打包外部商业音乐。
- `game/assets/fonts/Starport-CJK.otf`：Noto CJK 字体子集，沿用 SIL Open Font License；许可与版权记录保留在 `game/LICENSES/Noto-CJK.txt`。
- Godot：MIT 许可；引擎及其第三方说明保留在 `game/LICENSES/Godot-LICENSE.txt` 和 `Godot-COPYRIGHT.txt`。本仓库不分发引擎二进制。

素材中的旧 QA／生成目录引用记录制作历史，部分原始生成图与截图未包含在本源码快照内；这些历史链接不代表仓库包含对应文件。游戏运行使用的资源随源码提供。
